# Tesoreros SG (réplica editable)

Réplica simple de la interfaz de **Tesoreros SG** con campos configurables.

## Uso

1. Abre `index.html` en tu navegador.
2. Ingresa con PIN por defecto: `1234`.
3. Edita los campos desde el panel **Campos editables** y guarda.
4. Los cambios quedan en `localStorage` del navegador.

## Curso por URL

Puedes definir el curso con query string, por ejemplo:

```txt
index.html?curso=4b
```

El valor de `curso` se muestra en mayúsculas.
